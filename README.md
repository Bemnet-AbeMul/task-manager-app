# Full-Stack Task & Note Manager

A persistent RESTful web application built with Node.js and Express.

## Tech Stack & Features
* **Backend:** Node.js, Express.js (REST API handling GET, POST, DELETE)
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Data Persistence:** Synchronous filesystem management (`fs`)

## Local Execution
1. Clone repository: `git clone <repository-url>`
2. Install dependencies: `npm install`
3. Start server: `node server.js`
4. Open browser at `http://localhost:3000`
